# AGENT FACTORY

AIエージェントが働きやすい環境(ハーネス)を作る、スマホ縦画面向けのハーネス設計パズル。
アイソメトリックの箱庭オフィスを舞台にした、大人向けのカジュアルゲームです。
LLM の挙動は確率モデルによる擬似再現で、外部 API は呼びません。

## 遊び方

1. 📋 **案件** をえらぶ(1案件 = 2〜3分のステージ)
2. 🛠️ **開発** で、仕事の流れの各工程に **カード** を置く(⚡段取りポイントの範囲で)
   - 🔧ツール / 🔍チェック / 🔁リトライ / 🛡️ガード / 🙋人の承認 / 🧠メモリ / 📊ログ
   - LLM は ミニ・ミドル・ビッグから選ぶ。賢いほど⚡とコインがかかる
3. 🚀 **実行** して見守る。エージェントが不安になると「確認してください!」が出るので、回答案を見て OK か差し戻しを選ぶ
4. ⭐ 結果(正答率・自動処理率・運用コスト・誤送信)で★1〜3。★1でクリアして次の案件がひらく
5. 📈 **分析** で改善前後をくらべて、もう一回

コインで仲間(ベル、コロ)を採用でき、エージェントはレベルが上がると⚡段取りポイントが増えます。

## 開発

```bash
npm install
npm run dev       # http://localhost:5173(スマホ幅で表示)
npm test          # Vitest
npm run balance   # 案件ごとに代表的な構成を自動実行し、★の分布を出す
npm run build     # dist/ を出力。main に push すると GitHub Pages に公開
```

```
src/
  game/    画面に依存しないゲームロジック
    data.ts      カード・LLM・トラブル・案件・エージェント(数値はここに集約)
    engine.ts    実行エンジン(1工程ずつ進める純粋関数。シード付きで再現可能)
    progress.ts  報酬・★・レベル・採用
    storage.ts   IndexedDB 保存
  store.ts       Zustand(実行は画面を移動しても続く)
  ui/            オフィス・開発・案件・分析・実行・結果
scripts/balance.ts
tests/
public/          PWA(manifest、service worker、アイコン)
```

## バランス(`npm run balance`)

どの案件も「ビッグLLMを置くだけ」では★がとれず、「ミニLLM + 原因に合ったカード」で★3がとれるように調整しています。
